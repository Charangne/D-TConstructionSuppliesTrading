Install MatPrice on Android

Progressive Web App (PWA) • Works Offline

Option 1: One-Tap Home Screen Install PWA Ready

If you have this page open in Chrome on Android, tap below (or tap Chrome's ⋮ Menu → Add to Home screen) to install MatPrice as a full-screen app icon.

Option 2: Download Standalone App File (.HTML)

Save the self-contained MatPrice_PWA.html file directly to your Android phone so you can open it anytime without internet.

How to pin to your Android Home Screen:
1 Open the downloaded file or hosted link in Google Chrome on your Android phone.
2 Tap the top-right ⋮ three-dot menu and select Add to Home screen (or Install app).
3 Launch MatPrice from your home screen—it opens in full-screen monochrome bubble mode and works offline.
